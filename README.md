# Terminal Terrestre El Parque

Sitio web en HTML, CSS y JavaScript, organizado en tres carpetas:

- `HTML/`: páginas interiores.
- `JS_CSS/`: hojas de estilo y código JavaScript.
- `IMAGENES/`: imágenes y fotos del equipo.

`index.html` queda en la raíz para abrir el inicio con Live Server y para publicar el proyecto en Vercel. `vercel.json` conserva los enlaces antiguos como `/servicios` y `/galeria`.

## Actualizar el repositorio clonado con GitHub Desktop

1. En GitHub Desktop, selecciona `terminal-terrestre-el-parque` y usa **Repository > Show in Explorer**.
2. Extrae el contenido de este ZIP **dentro** de esa carpeta. Conserva la carpeta oculta `.git` del repositorio.
3. Borra la carpeta anterior `assets` y estos archivos antiguos de la raíz, pues ahora están dentro de las tres carpetas: `base.css`, `style.css`, `codigo.js`, `contactanos.html`, `desarrolladores.html`, `galeria.html`, `nosotros.html`, `proyecto.html` y `servicios.html`.
4. En GitHub Desktop verás los cambios. Escribe `Organizar proyecto en tres carpetas`, pulsa **Commit to main** y luego **Push origin**.
5. Espera a que el despliegue de Vercel diga **Ready**. Para probar localmente, abre `index.html` con Live Server desde la carpeta del repositorio.

Si ya estabas editando archivos en tu computadora, guarda una copia de tus cambios antes del paso 2.
